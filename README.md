# Bimodal Battery Electrode Optimization

A MATLAB-based computational modeling project investigating the optimal particle-size distribution of bimodal battery electrodes.

## Project Overview

This project evaluates mixtures of 4 μm and 8 μm spherical particles using 3D particle packing simulations in MATLAB.

Eleven different small-to-large particle ratios were simulated to evaluate particle packing density and volumetric capacity. The resulting capacity was then combined with specific power through Min-Max normalization to identify an optimal balance between power and capacity.

## Methodology

- 3D particle packing simulation using MATLAB
- Small particle diameter: 4 μm
- Large particle diameter: 8 μm
- 11 particle compositions from 0.0 to 1.0 small-particle fraction
- Calculation of particle volume fraction and effective material density
- Volumetric capacity analysis
- Specific power analysis
- Min-Max normalization for power-capacity optimization

## Key Results

- Maximum volumetric capacity: **Small 0.4 : Large 0.6**
- Maximum specific power: **Small-particle ratio = 1.0**
- Optimal balance between power and capacity: **Small-particle ratio = 0.5**
